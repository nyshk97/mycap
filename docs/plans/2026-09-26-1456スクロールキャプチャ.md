# スクロールキャプチャ

## 概要・やりたいこと
CleanShot X の Scrolling Capture と同じ体験を作る。オールインワン（⌘⇧5）で範囲を選んで Scrolling を押すと撮影が始まる。ユーザーが自分でスクロールすると、横のプレビューに縦長の画像が伸びていく。Done で 1 枚の縦長 PNG になり、いつものサムネイルが出る。
今の Scrolling ボタンは場所取りだけで、押しても何もしない（`AIOController.perform` の `if action == .scrolling { return }`）。ここに中身を入れる。

## 前提・わかっていること
- 現状（流用できる部品）
  - 範囲の選択とツールバーは `Sources/App/AIO/` にある。Scrolling ボタンのツールチップは「準備中」のまま
  - `Recorder` は SCStream でディスプレイのフィルタ（mycap を除外）＋`sourceRect` の範囲を流している。コマの受け取りはこれと同じ作りで、`SCRecordingOutput` の代わりに `SCStreamOutput` を使う
  - 範囲の外周の枠は `RecordingFrame`、範囲の右下の外に出すバーは `RecordingBar` がある（どちらも範囲の外に出すので写らない）
  - ⌘⇧5 の振り分けは `AIOController` が一手に持つ（録画中・カウントダウン中 → `recorder.toggle()`）
  - 撮影結果は `CaptureService.finish(tmp:kind:screen:app:)` に流せば、キャッシュへの保存・サムネイル・撮影元アプリの拡張属性まで済む
- 決定（/dig-lite）
  - スクロールはユーザーが手動で行う。自動スクロール（`CGEvent` によるスクロール送信）は入れない。アクセシビリティ許可を増やさないため
  - ライブプレビューは v1 から入れる
  - 終わらせる操作はバーの Done と ⌘⇧5。Cancel はバーのボタンだけ。Enter / Esc は取らない（暗幕が nonactivating なので、キーは前面アプリのものになる）
- 方式（会話で決定）
  - コマの受け取り: `SCStream` ＋ `SCStreamOutput`。`SCStreamFrameInfo.status` が `.complete`（画像が付いていれば `.started` も）のコマを処理し、`.idle`（画面が変わっていないコマ）は捨てる。`showsCursor = false`。ピクセル単位で扱い、範囲×scale の解像度で受ける（`pixelFormat` は BGRA、解像度は `FullScreenCapturer` に揃える。色空間は最初のコマの `CVImageBuffer` に付いているものを取っておき、書き出す画像に付ける）。`minimumFrameInterval` は 1/15 秒程度にし、照合は専用のシリアルキューで行い、処理中に届いたコマは最新の 1 枚だけを持っておき（あとから来たもので上書き）、今の処理が終わったらそれを処理する（スクロールを止めた位置のコマを落とさないため）
  - ズレの検出: 自前の「行シグネチャ」照合を `Sources/Core` に純粋関数として置く。Vision の `VNTranslationalImageRegistrationRequest` は固定ヘッダに引っ張られるうえテストしにくいので使わない
    - 各コマをグレースケールにし、1 行ごとの輝度の並び（横方向を間引いたもの）を作る
    - 比べる相手は常に**最後につないだコマ**（最後に受け取ったコマではない）。その `[dy..H]` と今のコマの `[0..H-dy]` を、誤差を許して比べ、一番よく一致する `dy` を選ぶ（`dy > 0` = 下へスクロールした）。上に戻してから下へスクロールし直しても、つないだ部分を二重に足さない
    - 1 位と 2 位のスコアが僅差で、離れた `dy` を指すとき（周期的なリスト・無地の重なり）は「あいまい」として捨てる
    - 固定ヘッダ・フッタ: 「中ほどの行が変わった組」で初めて決める（まだスクロールしていないコマ同士では決めない）。前後のコマで同じ位置のまま変わらない上端・下端の帯で、厚さはそれぞれ H の 1/3 までにする。照合とつなぎから外し、結果の画像にはヘッダを最初のコマから一番上に、フッタを最後につないだコマから一番下に 1 回ずつだけ入れる
    - 右端の 16pt ×scale（オーバーレイのスクロールバー）は照合から外す（つなぐ画像には含める）
  - つなぎ: 下へのスクロールで新しく見えた `dy` 行分を帯として足していく。`dy <= 0`（上へのスクロール・変化なし）や一致の弱いコマは捨てる。つないだものは帯のリストのまま持ち、1 枚の画像にまとめるのは Done のときだけにする
  - 範囲の中に動かない縦の帯（サイドバー等）が入る場合は扱わない。範囲はスクロールする部分だけを選ぶ前提にする（CleanShot と同じ。1回目で決定）
  - 速すぎるスクロールで最後につないだコマとの重なりが無くなったら、コマを捨て続けて待つ。最後につないだコマと比べているので、ユーザーが少し戻せば続きからつながる。知らせる表示は今回の範囲に入れない（1回目で決定）
  - 高さの上限: 30000px（ピクセル。ヘッダ＋本体＋フッタで数える）。超える帯は切って 30000px に収め、自動で Done にする
  - 出力: `FullScreenCapturer.writePNG` を共用に切り出し、DPI 72×scale の PNG を書いてから `CaptureService.finish` に kind `scrolling` で流す（書き出しはメインスレッドの外で）
- 操作仕様

  | 項目 | 仕様 |
  |---|---|
  | 開始 | オールインワンで範囲を選んで Scrolling を押すと、暗幕を閉じて撮り始める。カウントダウンは無い。範囲は `LastRegion` に保存する（他のアクションと同じ） |
  | 撮影中の表示 | 範囲の外周に枠（`RecordingFrame` を流用）。範囲の右下の外に Done / Cancel のバー。範囲の右の外にライブプレビュー（入らなければ左の外。どちらも無理なら範囲の内側の右端に重ねる）。プレビューはつないだ画像を幅に合わせて縮小し、最新（下端）が見えるように出す。プレビューの置き場所はバーの frame と重ならないように決める。表示はすべて mycap のウィンドウなので SCK のフィルタで写らない。枠とプレビューはマウスを素通しにして（`ignoresMouseEvents`）、範囲の中でスクロールできるようにする（バーは押せるようにする） |
  | 終了 | バーの Done か ⌘⇧5 → つないだ画像を保存してサムネイル。バーの Cancel → 何も残さず終わる。高さの上限に達したら自動で Done。一度もスクロールしていなければ、最初の 1 コマをそのまま出力する。1 コマも届かないうちに Done なら Toast を出して何も残さない。SCK 側から止まったとき（`didStopWithError`）は、そこまでつないだ画像を保存し、Toast で知らせる（`reason=stream_stopped`） |
  | ⌘⇧5 の振り分け | `AIOController` の先頭の判定に「スクロール撮影中（開始待ちを含む）→ Done」を足す |
  | 他のホットキー | 撮影中は `AIOController.isBusy` に含め、⌘⇧4・⌘⇧6・OCR・全画面・⌘⇧3 を止める（`screencapture -i` の UI がコマに写り込むため） |
  | メニューバー | 撮影中はステータスアイテムのクリックで Done。表示は録画と同じ ● と経過時間。`MenuBarController.refreshRecording` を「録画中かスクロール撮影中か」で分ける |
  | 同時実行 | 録画中・録画のカウントダウン中は Scrolling を始めない（その逆も） |
  | ツールバー | Scrolling のツールチップ「準備中」を外す |

- 罠・注意
  - Retina では `sourceRect` はポイント、受け取るコマはピクセル。照合とつなぎはすべてピクセルで行い、倍率を混ぜない
  - 慣性スクロール中のコマは、ちょうど描画の途中の状態で届くことがある。一致が弱い（しきい値以下）ものは捨て、次のコマで取り返す
  - 遅延読み込みや動画など、中身そのものが変わる部分があると一致が崩れる。v1 はしきい値で捨てるだけにし、深追いしない
  - 画面収録の許可が要る確認は、ad-hoc 署名だとリビルドのたびに許可が外れる。自動の検証は Core のテストと、コマ列をファイルから流すフックで行う

## ログ
### 試したこと・わかったこと
- 実機の SCStream（`--scroll-capture`）では、画面が止まっていても `.complete` のコマが 15fps のまま届き続けた。照合は dy=0 で捨てるので結果は正しいが、ログが埋まるので変化なしのコマは `scroll.frame` を出さないようにした
- コマの色空間は `CVImageBufferGetColorSpace` で取れ、出力 PNG は Display P3 になった（Studio Display）。照合は 800×600 のコマで 1 枚 20ms 前後（Debug ビルド）
- `.started` のコマの扱いは実機で確かめていない（最初のコマは `kind=first` で届いている）

### 方針変更
- 検証フック `--scroll-capture <x> <y> <w> <h> <秒>` を足した（実際の SCStream の経路を、暗幕を出さずに通すため。`--aio-record` と同じ扱い）。fixture の生成は `scripts/make_scroll_fixture.py`、画素の比較は `scripts/png_diff.swift` としてコミットする
- 高さの上限に達したときの Toast は、plan では見送りにしていたが 1 行なので入れた
- 録画バーの ■ ボタンを `BarButton`（`Sources/App/Record/BarButton.swift`）に切り出し、スクロールキャプチャのバーの Done / Cancel と共用にした
