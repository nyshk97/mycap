# 録画の音声（マイク・システム音）

## 概要・やりたいこと
今の動画録画（オールインワン ⌘⇧5 の Recording）は音声なし（`Recorder.swift` の `config.capturesAudio = false`）。
録画の前に次の 2 つを ON/OFF できるようにする。
- マイク
- システム音（Mac から出る音）

CleanShot X の録画で使っていた機能の置き換え。

## 前提・わかっていること
- deployment target は macOS 26。SCStreamConfiguration の `capturesAudio`（システム音）と `captureMicrophone`（マイク）で両方録れる。今と同じく SCRecordingOutput に書く
- システム音は今の画面収録の許可だけで録れる。mycap 自身の音（録画サムネイルのプレビュー等）は `excludesCurrentProcessAudio = true` で外す
- マイクには次が要る
  - `project.yml` の `targets.mycap.info.properties` に `NSMicrophoneUsageDescription`（`Sources/Info.plist` は XcodeGen の生成物なので直接書かない）
  - `mycap.entitlements` に `com.apple.security.device.audio-input`（Release は Hardened Runtime が有効なので、これが無いとマイクは黙って無音になる。make-release-zip.sh の再署名も同じファイルを使うので、足すのはここだけ）
  - マイクの許可（TCC）。初回は `AVCaptureDevice.requestAccess(for: .audio)` で OS のダイアログを出す
- マイクはシステムの既定の入力デバイスを使う。デバイスを選ぶ UI は作らない
- **決定: 切り替えの UI** — オールインワンのツールバーで、Recording の横にマイクとスピーカーのトグルを置く。状態は UserDefaults に残す（再起動・更新をまたぐ。初期値は両方 OFF）。録画中は切り替えられない（開始時に固定）。設定画面は作らない方針は変えない（トグルは撮影 UI の一部）
- **決定: 両方 ON のときの音声トラック** — 停止後に音声を 1 トラックへ混ぜて書き直す。映像はパススルー（再エンコードしない）。ブラウザ・Slack のプレビューは 1 本目の音声トラックしか鳴らさないことが多いため。混ぜている間はサムネイルが出るまで少し待つ
  - SCRecordingOutput がマイクとシステム音を別トラックに書くというのは見込み。Phase 1 で実物の mp4 を見て確かめる。最初から 1 本で書かれるなら、混ぜる処理（Phase 3）は要らない
- マイクが ON で許可が無い・拒否されたとき: トーストで知らせて、マイクなしで録る（録画自体は止めない）
- 1 トラックへ混ぜるときの音量比はマイク:システム音 = 1:1 で始め、動作確認で聞いて必要なら直す（1回目で決定）
- 録画サムネイルの 🔊 表示（`ThumbnailController` の `hasAudio`）は今のまま効く
- 会社貸与 PC ではセッションからのビルドが ad-hoc 署名になるので、実際に録る確認（画面収録・マイクの許可が要る）はユーザーが自分の Terminal の `mise run run` で行う

## 実装計画

### Phase 1: 録音の経路と実物の確認 [AI🤖]
- [x] `RecordingAudio`（mic / system の Bool）を UserDefaults で持つ型を足す（`LastRegion.swift` と同じ書き方）。Recorder は録画の開始時にこれを読む（トグルの状態の正はここ 1 か所）
- [x] `Recorder.start(with:)` で `capturesAudio` / `captureMicrophone` / `excludesCurrentProcessAudio` を設定する。`record.started` のログに `mic= system=` を足す
- [x] マイク ON のときは録画の開始前（`start(screen:rect:app:)` ではカウントダウンの前）に `AVCaptureDevice.authorizationStatus(for: .audio)` を見る。未決定なら `requestAccess` を出し（待っている間も `.countdown` にして 2 重の開始を防ぎ、⌘⇧5 で取り消せるようにする）、返事を main に戻してからカウントダウンを始める（ダイアログが写ったり、返事の前に録画が始まったりしないように）。拒否・restricted ならトーストを出してマイクなしで続ける（`record.mic_denied` をログに出す）。この確認は Recorder の 1 つの関数にし、検証フックの入口 `startForTest`（`begin` を直に呼ぶ）からも通す。`startForTest` の停止タイマーは返事を待って録り始めてから数える
- [x] `project.yml` の `info.properties` に `NSMicrophoneUsageDescription`、`mycap.entitlements` に `com.apple.security.device.audio-input` を足す
- [x] 音声を指定する独立した検証フック（例 `--record-audio mic,system|none`）を足す。フックは前から順に処理されるので、録画のフックより前に置く
- [x] `record.captured` のログに `audio_tracks=`（`AVURLAsset.loadTracks(withMediaType: .audio).count`）を足す

### Phase 1 の後の確認 [人間👨‍💻]

### Phase 3前の判断 [AI🤖]
- [ ] 上の確認の結果、音声トラックが 1 本ならこの Phase を取り消し線にして、ログ > 方針変更 に理由を書く

### Phase 3: 停止後に音声を 1 トラックへ混ぜる [AI🤖]
- [x] 音声トラックが 2 本以上あるときだけ書き直す。映像は `AVAssetReaderTrackOutput(outputSettings: nil)` のパススルー、音声は `AVAssetReaderAudioMixOutput` で 1 本の PCM として読み、AAC で `AVAssetWriter` に書く。1 本以下なら何もしない
- [x] `Recorder.finishRecording` で `CaptureStore.keep` の前に挟む。失敗したら元の 2 トラックの mp4 をそのまま置く（録画を失わない）。混ぜている間は `Recorder` を idle に戻さない状態（`.stopping` とは別）にし、⌘⇧5・メニューバーからは `.stopping` と同じに扱う。停止のタイムアウトから `finishRecording` に再び入らないようにする。`record.audio_mixed tracks= ms=` / `record.audio_mix_failed` をログに出す
- [x] 純粋関数に切り出せる部分（トラック本数から混ぜるかどうかの判定など）は `Sources/Core` に置いてテストする
- [ ] 混ぜる時間は `record.audio_mixed ms=` に出し、動作確認で数分録ったときの値をログ > 試したこと に書く（実録画は許可が要るので人の確認で測る）

## ログ
### 試したこと・わかったこと
- 2026-09-26 システム音だけの実録画（`--record-audio system --aio-record 200 150 333 211 3`）→ `record.started mic=false system=true` / `record.captured audio_tracks=1`
- 混ぜる処理は 2 本の音声トラックの fixture（ffmpeg で 440Hz ステレオ＋880Hz モノラル、3 分）を `--mix-audio` に流して確認: 音声 1 本・2ch・180 秒、映像は元とビット一致、440Hz / 880Hz とも -21〜-24dB で残る（1500Hz は -54dB）。3 分で 1096ms

### 方針変更
- Phase 3 を「Phase 1 の後の確認」の前に実装した。トラックが 1 本なら `needsAudioMix` が false で何もしない経路なので、先に入れても無害で、確認の往復が 1 回減る。確認の結果 1 本だった場合は AudioMixer を消すかどうかをそこで決める
- 許可なしで混ぜる処理を確かめる検証フック `--mix-audio <in.mp4>` を足した（レビューでは見送りにしていたが、実録画なしで Phase 3 を確かめる手段が他に無かったため）
