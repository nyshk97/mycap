# スクショ編集

## 概要・やりたいこと
いまの「整形」（背景・余白・角丸・影を付ける）をやめて、撮った画像の中に注釈を描き込む「編集」に置き換える。CleanShot X の Annotate のうち、使うものだけを持つ。

- 矢印（初期値は赤。色と太さを変えられる。形は CleanShot に寄せる）
- 四角い囲み（初期値は赤。色と太さを変えられる）
- モザイク
- 文字（初期値は赤。色・大きさ・フォントを変えられる）

スクショの周りに付ける枠・余白・角丸・影は全部やめる。

## 前提・わかっていること
- 現状: サムネイル左下の「整形」ボタンと ⌘E で `StylePanelController`（560×520 の固定パネル。900px に縮小したプレビュー）が開く。保存すると `StyleService.export` が `_styled.png` を元と同じフォルダ（キャッシュ）に書き、`onExported` で**新しいサムネイルを追加**している（`CaptureService.swift:13-14`）。描画は `Sources/Core/StyleRenderer.swift` の純関数で、テストは `StyleRendererTests`
- 整形は丸ごと削除する: `StyleRenderer` / `StyleSettings` / `StyleService` の設定の記憶（UserDefaults の `styleSettings`）/ `StylePanel` / `StyleRendererTests` / 検証フック `--style*`
- サムネイル左下のボタンと ⌘E は残し、「編集」を開くものにする（ツールチップも「編集（⌘E）」に）
- 編集モデルは**保存まで編集できる**方式（ユーザー判断）: 描いた要素はデータ（`[Annotation]`）として持ち、保存までは選択・移動・リサイズ・色や太さの変更・削除・文字の打ち直しができる。画像に焼き込むのは保存のときだけ
- ツールバーはタイトルバーと 1 段（NSToolbar の unified。タイトルは出さない）。中央にツール 4 つ（選択中は淡いグレー、文字のアイコンは「T」）・色・太さ、右に取り消し・やり直し・保存（青い角丸に ✓。角丸はツールと同じ 7）。色と太さはどちらも「今の値 ＋ ▾」のボタンで、押すとポップオーバー（太さはスライダー、文字はフォントもここで選ぶ）
- ツールの切り替えキー（修飾なし・文字の入力中は効かない）: A 矢印 / R 四角 / P モザイク / T 文字
- ⌘Z / ⌘⇧Z で取り消し・やり直し。選択中の要素は Delete / Backspace で消す
- 編集ウィンドウは**リサイズ可能**にし、開いたときは画像が原寸（ポイント）で収まる大きさ、収まらなければマウスのある画面の `visibleFrame` に収まるまで縮める。キャンバスの座標は**画像のピクセル座標**で持ち、表示倍率で割って描く（保存時の焼き込みと同じ座標系にするため）
- 保存（Enter でなく ⌘S と「保存」ボタン。文字入力中の Enter と衝突するため）: キャッシュに `<元の名前>_edited.png` を書き、**元のサムネイルをそれに置き換える**（ユーザー判断。同じ位置に出し直す）。元の画像はキャッシュに残り、キャプチャ履歴から戻せる。`~/Downloads` への保存とコピーはこれまでどおりサムネイルのボタンから
- 編集済みを再編集したとき: 注釈は焼き込み済みなので、その画像を元として開く。名前は `_edited_edited` にせず `_edited_2`…（`FileNaming.uniqueName` の既存の規則）にする
- キャプチャ履歴は `_styled` をファイル名から時刻が取れない例として扱っている（`CaptureHistory` のテスト・VERIFY.md の記述）。`_edited` に読み替える
- 保存時は元画像の xattr（前面アプリ）と DPI を引き継ぐ（いまの `export` と同じ）
- ツールごとの仕様

  | ツール | 操作 | 変えられるもの | 初期値 |
  |---|---|---|---|
  | 矢印 | 始点から終点へドラッグ | 色・太さ | 赤・6pt |
  | 四角い囲み | 対角をドラッグ（⇧ で正方形） | 色・太さ | 赤・6pt |
  | モザイク | 矩形をドラッグ | 粗さ（ブロックの一辺） | 10pt |
  | 文字 | クリックした位置に入力欄を出す。Esc / 外クリックで確定 | 色・大きさ・フォント | 赤・中・ヒラギノ角ゴ W6 |

- 色は 8 色のプリセット（赤・橙・黄・緑・青・紫・白・黒）。ツールバーには今の色だけを出し、押すとポップオーバーで 8 色から選ぶ。太さ・文字の大きさ・モザイクの粗さはスライダー 1 本（pt。今のツール／選んでいる要素の種類に応じて切り替わる）
- フォントは数種のプリセット（ユーザー判断）: ヒラギノ角ゴ W3 / W6、ヒラギノ丸ゴ、ヒラギノ明朝、SF Mono。全フォント一覧は出さない
- 矢印の形（CleanShot 風）: 始点が細く終点に向かって太くなる軸＋塗りつぶしの三角の頭。頭の大きさは太さに比例。縁取りは付けず、柔らかい影（下向き）を付ける。四角・文字にも同じ影
- モザイクは**元画像の該当矩形をピクセル化**する（ぼかしは作らない）。重ね順は「モザイクが一番下、その上に図形と文字」ではなく**描いた順**にする（CleanShot と同じ。後から描いた矢印がモザイクで消えないように、ピクセル化は常に元画像から取る）
- 選択中はツールで描いた最後の要素が選ばれた状態になり、ツールバーの色・太さを変えるとその要素に効く。何も選んでいないときの変更は次に描く要素の初期値になる（アプリを再起動したら赤に戻る。前回の設定の記憶はしない）
- 描画の焼き込みは Core の純関数（`AnnotationRenderer.render(image:annotations:) -> CGImage`）にして、画素でテストする。編集ウィンドウの表示も同じ関数で描く（見た目と出力を一致させる）。ただし文字の描画は CoreText を使う
- 検証は既存の検証フック方式（dev 版のみ・フォーカスを奪わない）。注釈は JSON で流し込めるようにする。実際にマウスで描く確認はユーザーが自分の Terminal の `mise run run` で行う（CLAUDE.md の会社貸与 PC の制約）
- 前提の作業ツリー: キャプチャ履歴（`docs/plans/2026-09-26-1233キャプチャ履歴.md`）の変更が未コミットで残っている。着手前にそちらをコミットしてから始める

## ログ
### 試したこと・わかったこと
- モック: `<scratchpad>/mock/editor.html`（矢印 A 影なし / B 白い縁取り / C 柔らかい影）。C で実装
- 影はデバイス空間で効くので、`ctx.userSpaceToDeviceSpaceTransform.a` を掛けて編集画面（縮小表示・Retina）と書き出しで見た目の大きさを揃えた。左上原点に反転した座標系でも影の向きは反転しないので、下向きは y を負にする
- 常駐アプリでメニューバーが無いため、⌘Z / ⌘S / ⌘W と文字入力中の ⌘C / ⌘V / ⌘X / ⌘A はウィンドウの `performKeyEquivalent` で受けて振り分けた
- 検証フック中に、ユーザーが dev 版で ⌘E を押して描いていたモザイクを `--edit-close`（確認なしで破棄）と `--close-all` で消してしまった。VERIFY.md に「ユーザーが触っている間は撃たない・撃つ前にログを見る」を追記
- 大きい画像（5120×2880pt）で画面に収まるまで縮むことは、上の事故のあとフックを止めたので実機では未確認（`initialSize` の計算上は Studio Display で 2208×1296）

### 方針変更
- 太さ・大きさは「小 / 中 / 大の 3 段＋スライダー」でなくスライダー 1 本にした（3 段と連続値の 2 つの操作を持つ理由が薄い）。モザイクの粗さも同じスライダーで変えられる
- 描きかけがあるときに別の画像の編集を開こうとしたら、開かずにトーストで知らせる（黙って捨てない）
