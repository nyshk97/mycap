# オールインワン（⌘⇧5）

## 概要・やりたいこと
今の ⌘⇧5 は、OS 標準のピッカー（`SCContentSharingPicker`）でディスプレイかウィンドウを選び、3 秒のカウントダウンのあと録画を始める。
これを CleanShot X の All-In-One のような流れに変える。まず範囲をドラッグで選ぶ。するとツールバーが出て、その範囲を撮る・タイマーで撮る・録画する、を選べる。
範囲を選んでから「何をするか」を決められるので、静止画と動画の入口がひとつになる。範囲の録画もできるようになる。

## 前提・わかっていること
- 現状
  - ⌘⇧4 の範囲選択は OS の `screencapture -i` に任せている（`ScreenCapturer`）。選んだ直後にツールバーを出せず、サイズの数値入力もできない → オールインワンの範囲選択は**自前の画面**で作る。⌘⇧4 はこのまま変えない
  - 範囲を撮る部品はもうある: `FullScreenCapturer.capture(screen:rect:)` は SCK の `sourceRect` で範囲を撮り、自分のウィンドウは写さない（⌘⇧6 前回の範囲で使っている）
  - 録画は `Recorder`（SCStream ＋ SCRecordingOutput）。ディスプレイを録るときは自分のアプリを外したフィルタに作り直しているので、範囲の録画は `SCStreamConfiguration.sourceRect` を足せばできる見込み
  - 「前回の範囲」は `LastRegion`（ディスプレイ ID ＋ ディスプレイ内の左上原点のポイント）
- 決定（/dig-lite）
  - 流れ: 範囲を先に選ぶ（CleanShot と同じ）
  - Recording で録るのは選んだ範囲だけ。`SCContentSharingPicker` による録画はやめる
  - Timer は 3 秒固定（設定画面は作らない方針）
- 操作仕様

  | 項目 | 仕様 |
  |---|---|
  | 起動 | ⌘⇧5（dev は ⌃⌥⌘5）とメニューの「オールインワン」。画面収録の許可を先に確かめる（`ensurePermission`）。マウスのあるディスプレイに暗幕を出す（1 画面だけで、2 画面をまたぐ範囲は選べない）。先に `disarm(reason: "aio")` で待ち受けを解き、サムネイルは `setHidden(true)` で隠す。隠している間はホバーで取った Carbon のキー（Esc 等）も放す（放さないと暗幕や `Countdown` の Esc を取られる）。サムネイルは暗幕を閉じたとき（キャンセルを含む）に戻す |
  | ⌘⇧5 の振り分け | 1 か所（`AIOController`）で次の順に判定する: 録画中・録画のカウントダウン中 → `recorder.toggle()`（停止／キャンセル）、Timer のカウントダウン中 → キャンセル、暗幕が出ている → 閉じる、どれでもない → 開く |
  | 範囲を選ぶ | ドラッグで範囲を作る。選び終わったら、範囲の内側は明るく外側は暗いままにする。範囲の内側をドラッグすると移動、四隅と四辺のハンドルでサイズを変える。範囲の外をドラッグすると選び直し。クリックだけ・16pt 未満のドラッグは無視して今の範囲を残す（範囲が無ければ何もしない）。Esc で全体をキャンセル |
  | ツールバー | 範囲の下に出す。下に入らなければ上、それも無理なら範囲の内側の下端に出す。ディスプレイからははみ出させない。並びは **Capture / Scrolling / Timer ｜ Recording**。見た目は参考画像（暗い半透明の角丸、アイコン＋ラベル） |
  | サイズ欄 | ツールバーの右に W × H を**ポイント**で出す（`LastRegion` と SCK の `sourceRect` がポイントなので揃える。1回目で決定）。ドラッグに追従する。開いた直後のフォーカスは暗幕のビューに置き、欄はクリックしたときだけ編集に入る。数値を打って Enter で、左上を固定したままサイズを変える（ディスプレイに収まるよう切り詰める）。欄の編集中の Enter は反映して編集を終えるだけで、Capture しない。編集中の Esc は編集の取り消し。縦横比プリセットの切り抜きメニューは作らない |
  | Capture | 暗幕を閉じてその範囲を撮る（`FullScreenCapturer`）→ 既存の `finish`（キャッシュに置いてサムネイル＋待ち受け。kind は `aio`）。欄を編集していないときの Enter でも Capture |
  | Scrolling | 押しても何もしない（今後の機能の場所取り）。見た目は他と同じにし、ツールチップで「準備中」と出す |
  | Timer | 暗幕を閉じ、3 秒のカウントダウン（`Countdown` を流用）のあとその範囲を撮る。カウントダウン中は Esc か ⌘⇧5 でキャンセル |
  | Recording | 暗幕を閉じ、3 秒のカウントダウンのあとその範囲を録る。録画中は範囲の**外側**に細い枠を出す（`sourceRect` の外なので、SCK のアプリ除外が効かなくても写らない）。停止は ⌘⇧5 かメニューバー |
  | 前回の範囲 | Capture / Timer / Recording のどれでも、`AIOController` でアクションが決まった時点に 1 回だけ `LastRegion` に保存する（⌘⇧6 で同じ範囲を撮れる） |
  | 撮るときのアプリ | 暗幕を出す前の前面アプリを覚えておき、撮影元の bundle id・待ち受けの戻る先に使う。暗幕は mycap を前面にしない（下の罠） |

- 罠・注意
  - 暗幕は数値入力と Esc を受けるので key にする必要がある。ただしアプリを前面にすると元のアプリが非アクティブの見た目で写るので、`.nonactivatingPanel` の NSPanel で `canBecomeKey = true` にし、アプリは前面にしない（`activate` で戻す処理も要らない）（1回目で決定）
  - 暗幕は mycap のウィンドウなので SCK のフィルタで外れ、写らない
  - `Recorder` から picker を外すと、`finishPicker` と `picking` の状態も要らなくなる。録画の検証フック `--record-display` はそのまま残す
  - 検証で暗幕を出すとユーザーの画面を塞ぐ。AI からは暗幕を出さず、「範囲が決まった後」の経路と、描画のスナップショットで検証する（`screencapture -i` を撃たないのと同じ理由）

## ログ
### 試したこと・わかったこと
- 2026-09-26 個人 PC で `env -u CLAUDECODE mise run run` した版（許可あり、`MYCAP_ARM_KEYS=0`）で確認: `--aio-capture 100 80 400 300` → `capture.aio.captured px=800x600`（Studio Display・2x）と `region.remembered`。`--aio-record 200 150 333 211 3` → `record.started size=332x210`、ffprobe で h264 332×210、1 コマ抜いて赤い枠が写っていないことを確認。`--aio-snapshot` で中央・画面いっぱい（内側の下端に出る）の配置と W × H を目視
