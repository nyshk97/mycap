# キャプチャ履歴

## 概要・やりたいこと
CleanShot X の Capture History に相当する機能を作る。キャッシュに残っている撮影結果を画面上部の横長パネルに並べ、選んだものを撮影直後と同じ左下のサムネイルに戻す（Restore）。戻したあとは保存・コピー・OCR・ピン留め・整形を通常どおり使える。

## 前提・わかっていること
- 履歴の元はキャッシュ（`Env.cacheDir`）。撮影結果は `CaptureStore.keep` でここに `YYYY-MM-DD_HH-mm-ss.<ext>` の名前で置かれる。整形の出力も同じ経路で入る
- キャッシュの保存期間を **24 時間 → 7 日** に延ばす（`CacheRetention.maxAge`）。掃除は起動時に加えて 1 日 1 回も回す（起動しっぱなし対策）
- Restore は既存の `ThumbnailController.add(url:screen:)` に URL を渡すだけで済む
- 操作仕様

  | 項目 | 仕様 |
  |---|---|
  | 呼び出し | 常用 ⌘⇧3 / dev ⌃⌥⌘3（`HotKeys` に追加）＋メニューバーの項目。開いている間に同じキーで閉じる |
  | 表示位置 | マウスのある画面の上端に横長パネル（画面 1 枚でも 2 枚でも同じ） |
  | タブ | Screenshots（png。デフォルト）/ Videos（mp4）の 2 つ。All・GIFs は作らない |
  | 並び | 新しい順に横並び、横スクロール |
  | 各項目 | サムネイル（動画は先頭フレーム＋長さ）、右下にアプリアイコン（取れたものだけ）、下に相対時刻（`23 minutes ago`） |
  | 相対時刻の元 | ファイル名の日時（`FileNaming.date(fromName:)`）。規則外の名前（整形の出力 `_styled`）だけ作成日時 |
  | フォーカス | マウスホバー or ←→ キーで移動。開いた直後は先頭。フォーカス中は青枠＋相対時刻の位置が `↩ Restore` ボタンに変わる |
  | Restore | Enter / ダブルクリック / Restore ボタン → そのファイルを左下のサムネイルに出し、履歴パネルを閉じる |
  | 閉じる | Esc / パネル外クリック（key を失う）/ 同じホットキー / Restore |
  | タブ切替 | タブのクリック（キー操作は ⇥ で切替、任意） |
  | 削除 | 作らない |

- キー入力（←→ / Enter / Esc）を受けるため、パネルは開いている間だけ key にしてアプリをアクティブにする（閉じたら前のアプリに戻す）
- アプリアイコン: 撮影の瞬間に前面だったアプリの bundle id を、`CaptureStore.keep` の時点でファイルの xattr（例 `io.github.nyshk97.mycap.app`）に書く。範囲選択中は OS の選択 UI が前面になるので、**撮影開始前**の `NSWorkspace.shared.frontmostApplication` を控えておく。実装以前のファイル・整形の出力（前面が mycap 自身）はアイコンなし
- 動画の先頭フレーム・画像の縮小はパネルを開くたびに非同期で作る（数十件・7 日分なので、まずキャッシュなしで様子を見る）
- 検証は既存の検証フック方式（dev 版のみ・フォーカスを奪わない）で行い、実際に撮る確認はユーザーが自分の Terminal で行う（CLAUDE.md の会社貸与 PC の制約）

## ログ
### 試したこと・わかったこと
- `--ingest` のコピー（clonefile）は作成日時・更新日時を元ファイルから引き継ぐ。作成日時で並べると 13 時間前の fixture 由来のファイルが「13 hours ago」になり順序も崩れたので、計画どおりファイル名優先に戻した。あわせて `CaptureStore.keep` で作成・更新日時を置いた時刻にそろえる（掃除が元ファイルの mtime で早まらないように）
- 整形の出力は元画像の xattr（アプリ）を引き継ぐ。範囲撮影中に Space でウィンドウを選んだ場合も、アイコンは撮り始めの前面アプリ（選んだウィンドウの持ち主ではない）。録画のウィンドウ選択は `owningApplication` を使う

### 方針変更
- CHANGELOG はリリース時に `git log` から書く運用（docs/CHANGELOG.md の「書き方」）なので、実装時の追記ステップは取り消し
- 検証フックで開いたとき（activate: false）は Restore で閉じても前のアプリを activate しない（フォーカスを動かしていないのにユーザーのアプリを前面に出してしまったため）
